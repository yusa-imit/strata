# Plan 001 — Zig 0.16 migration and Tiger Style baseline

## Goal

Move strata to Zig **0.16.0** end to end (source, `build.zig.zon`, CI) and arm the Tiger Style
enforcement Phase 1 is written under: a `tidy` step inside `zig build test`, the kingdom `io: Io`
convention in the public API design, an assertion ratchet. Ends with a released **v0.2.0** whose
README no longer over-claims.

## Why now

strata is a 3-commit bootstrap: 265 LOC of stubs, 11 compile-check tests, zero real logic. The
0.16 probe found **1 error class in 1 file** (`src/main.zig`); `build.zig` is already 0.16-clean
and the library compiles and passes on 0.16.0 unmodified. This is the cheapest moment to migrate
and the only one where tidy, `io: Io`, and assertions cost nothing retroactively. Phase 1A (codec)
follows immediately and must be 0.16-shaped from its first line (`citadel/core/rules/zig-0.16.md`:
"never write new 0.15-only code").

## Out of scope

- **Any Phase 1 implementation** — no `codec`, `file`, `page`, `wal` logic lands here; 1A opens the
  cycle after this plan closes, written against the shapes fixed above.
- Benchmarks and the PRD §5 performance targets — nothing exists to measure yet.
- `docs/plans/000-inherited.md` (frozen history) and the PRD phase list beyond the §4 signatures.

## Risks

- **Claim-vs-reality gap (STATE.md).** README and PRD read as a status report for a 10-module
  storage kernel that is 0% implemented; the README item must land in the same milestone as the
  v0.2.0 tag, or the tag advertises vapour.
- **Thin CI track record (STATE.md).** Three runs total; the bootstrap commit failed and its fix
  has run twice. The 0.16 pin re-runs the 7-job matrix — the macOS/Windows cross-compile legs,
  never green on 0.16, are where surprises land.
- **`zig build test` hides `main`** (probe): the harness never analyses `main`'s body, so a broken
  entrypoint reads green. Every 0.16 item verifies with `zig build` *and* `zig build run`.
- **Ratchets set too tight, too early** (tidy red zone, assertion density): with no real bodies the
  floor is trivially met and could block Phase 1 on style, not substance. The exception table may
  only shrink — a Phase 1 PR needing an entry files it with a reason.

## Done when

- `zig build`, `zig build run -- version`, `zig build test` all exit 0 under Zig 0.16.0, and the
  `tidy` step runs inside `test` and fails on each ban-list fixture.
- `build.zig.zon` has `.minimum_zig_version = "0.16.0"`; CI pins no `version:`, 7/7 jobs green on
  `main`; `docs/adr/0001-io-injection.md` and `CHANGELOG.md` exist.
- `git tag` contains `v0.2.0` and `gh release view v0.2.0` succeeds.

## Version impact

**none** — a 0.x MINOR bump, 0.1.0 → **0.2.0** (`citadel/protocol/VERSIONING.md`: a milestone of
additive changes is MINOR; MINOR may break during 0.x). Not MAJOR: the toolchain move changes no
public signature any consumer compiled against — strata has no tag and no dependents. The
`io: Io` convention lands in `docs/PRD.md` as design, not shipped API, so no consumer `migration`
issues follow.
